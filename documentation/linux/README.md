# RASCAL Linux — Documentation

This directory contains Linux-specific documentation for RASCAL Desktop.

## Installation

Download the Linux package from [`../../download/linux/`](../../download/linux/).

| Package | How to install |
|---------|----------------|
| AppImage | Make executable with `chmod +x Rascal-*.AppImage` and run directly. |
| `.deb` | Install with `sudo dpkg -i rascal-*.deb` and resolve dependencies with `sudo apt-get install -f` if needed. |

## What is covered here

- Installation steps for AppImage and `.deb` packages
- System dependencies (OpenGL, Python)
- Desktop integration and shortcuts
- Troubleshooting
