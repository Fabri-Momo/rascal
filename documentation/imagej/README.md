# RASCAL for ImageJ/Fiji — Documentation

This directory contains the user manual and reference documentation for the RASCAL ImageJ/Fiji plugin.

The user manual is available here: [`Rascal _ImageJ_user_manual.pdf`](./Rascal%20_ImageJ_user_manual.pdf).

## Installation

Download the plugin `.jar` from [`../../download/imagej/`](../../download/imagej/) and copy it into the `plugins/` folder of your ImageJ or Fiji installation. Restart ImageJ/Fiji to load the plugin.

## What is covered here

- Plugin installation
- Launching RASCAL from ImageJ/Fiji
- Processing the current image or stack
- Parameter tuning and result export
- Macro scripting and batch processing
