# RASCAL Web / WebGL — Documentation

This directory contains the user manual and reference documentation for the browser-based WebGL implementation of RASCAL.

The user manual is available here: [`Rascal _WebGL_user_manual.pdf`](./Rascal%20_WebGL_user_manual.pdf).

## Access

The WebGL version runs directly in a modern web browser without installation. Open the `web/` directory in a local or hosted web server and navigate to the HTML entry point.

The source code is in [`../../web/`](../../web/).

## What is covered here

- Running the WebGL demo locally
- Supported browsers and limitations
- Loading images and basic controls
- Teaching and demonstration workflows
