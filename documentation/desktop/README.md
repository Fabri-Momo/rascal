# RASCAL Desktop — Documentation

This directory contains the user manual and reference documentation for the RASCAL Desktop application (Windows, macOS and Linux).

The generic user manual is available here: [`Rascal _Desktop_user_manual.pdf`](./Rascal%20_Desktop_user_manual.pdf).

## Source code

The desktop source code is available in [`../../desktop/`](../../desktop/).

## Installation

Download the installer for your operating system from [`../../download/`](../../download/).

| OS | Package | Location |
|----|---------|----------|
| Windows | `.msi` installer | [`../../download/windows/`](../../download/windows/) |
| macOS | `.dmg` disk image | [`../../download/macos/`](../../download/macos/) |
| Linux | AppImage or `.deb` | [`../../download/linux/`](../../download/linux/) |

## What is covered here

- Installation and first launch
- Loading and processing images
- Using the 3D colour cloud
- ROI processing
- Session recording (`.rasc` files)
- 3D textured model processing (OBJ/PLY)
- Reproducibility and publication-grade exports
