# RASCAL Android — Documentation

This directory contains the user manual and reference documentation for the RASCAL Android application.

The user manual is available here: [`Rascal _Android-user_manual.pdf`](./Rascal%20_Android-user_manual.pdf).

## Source code

The Android source code is available in [`../../android/`](../../android/).

## Installation

Download the latest `.apk` from [`../../download/android/`](../../download/android/). On your Android device, enable *Install from unknown sources* for your file manager, then open the `.apk` to install.

## What is covered here

- Installing the APK
- Loading images from the gallery or camera
- Touch controls and parameter adjustment
- Saving and sharing results
