## How to use

Open any image with RASCAL Desktop using **File > Open image**. For the 3D model, use **File > Open 3D model** and select `arcy.obj`.

To reproduce the figures of the article, use the corresponding `.rasc` session files located in the [`reproducibility/`](../reproducibility/) directory.
